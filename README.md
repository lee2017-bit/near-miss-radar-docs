# Near-Miss Radar

Robots and forklifts already see the close calls nobody reports. **Near-Miss Radar** is an Atlassian Forge app for Jira that collects near misses from machines and people, raises hotspots as Jira work items, and verifies whether each fix worked.

- [Setup guide](SETUP.md)
- [Machine event format](EVENT_SCHEMA.md)
- [Privacy policy](PRIVACY.md)
- [Support](SUPPORT.md): questions and bug reports go to [Issues](https://github.com/lee2017-bit/near-miss-radar-docs/issues)

Built for Atlassian Codegeist 2026. Runs entirely on Atlassian Forge (no egress). It is observation analytics, not a functional safety system.
